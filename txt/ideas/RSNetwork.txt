include command: <include> RSNetwork

Its purpose is to make servers or webpages available locally and to access the web using Wi-Fi.


network stuff: EspOnly

	constants:
		ROUTEMODE_CRE string = "CRE"   ## CRE = Connect to Existing Router: station mode, ESP joins an existing router
		ROUTEMODE_SR string = "SR"     ## SR = Self Router: access point mode, ESP creates its own network
		ROUTEMODE_MB string = "MB"     ## MB = Man in Between: dual mode, station + access point at the same time


	functions:
		RSNetwork.wifi() -> ModuleObject; returns the Wi-Fi handler for the current program.
		Get the handle first: v wifi ModuleObject = RSNetwork.wifi(), then call wifi.connect(...) or wifi.set_route_mode(...). The methods below are called on that handle.
			get_all_networks() -> string; returns every visible Wi-Fi network name (SSID) as one string, separated with ", ".
			connect(ssid string, password string) -> bool; connects to the given network with the password. Returns false if the connection fails.
			set_route_mode(mode string) -> bool; mode must be RSNetwork[ROUTEMODE_CRE], RSNetwork[ROUTEMODE_SR] or RSNetwork[ROUTEMODE_MB]. Any other value throws an error.
			get_ip(ssid string) -> string; returns the device's own IP when ssid is the runner device's own SSID, otherwise the IP associated with the given SSID. Throws an error if the SSID cannot be resolved.
			get_ssid(ip string) -> string; returns the SSID associated with the given IP, for example "192.168.1.4". Throws an error if no network matches.
			disconnect() -> bool; disconnects from the currently connected network. Returns true on success, or false if there was no connection.
			get_route_mode() -> string; returns the current route mode: RSNetwork[ROUTEMODE_CRE], RSNetwork[ROUTEMODE_SR] or RSNetwork[ROUTEMODE_MB].
			set_route_info(ssid string, password string) -> bool; sets the access-point name and password. Only usable in SR mode; in other modes it throws "RSNetwork.set_route_info: only usable in SR mode".
			get_own_route_info() -> string; returns the route info with the password masked as X***Y. Call it inside print_cmd() to display it.

		RSNetwork.create_wifi_data_process_handler() -> ModuleObject; creates the handler for constantly changing Wi-Fi data such as the current network speed. Create it in START(). It updates itself internally, so the program does not call process() on it; process() is not an RSNetwork function.
			get_global_speed() -> float; returns the currently connected network's global speed, calculated from the download and upload speed. Call it on the handler created in START(), normally in PROCESS(FPS). It is available only after the handler has been created.


	Usage:
		<include> RSNetwork

		c FPS float = 10.0
		v wifi_handler ModuleObject = RSNetwork.wifi()
		v wifi_data_handler ModuleObject = RSNetwork.create_wifi_data_process_handler()

		START():
			## Connect to an existing Wi-Fi network
			wifi_handler.set_route_mode(RSNetwork[ROUTEMODE_CRE])
			print_cmd(wifi_handler.get_all_networks())

			v connected bool = wifi_handler.connect("network_name", "password")
			if connected:
				print_cmd("Connected to Wi-Fi")
				print_cmd(wifi_handler.get_route_mode())
				print_cmd(wifi_handler.get_ip("device_ssid"))
				print_cmd(wifi_handler.get_ssid("192.168.1.4"))
			else:
				print_cmd("Could not connect to Wi-Fi")

			## To use the ESP as an access point, use these instead of the
			## router connection setup above:
			## wifi_handler.set_route_mode(RSNetwork[ROUTEMODE_SR])
			## wifi_handler.set_route_info("network_name", "password")
			## print_cmd(wifi_handler.get_own_route_info())

		PROCESS(FPS):
			print_cmd(wifi_data_handler.get_global_speed())




hosting a website/server: EspAndPc

	The main goal is for the hosting hardware to have as little work to do as possible. The server stores and serves HTML and one static JavaScript file; it does not run JavaScript or CSS on the host. The client may use JavaScript, CSS, and other client-side technologies.


	functions:
		RSNetwork.html_server_handler() -> ModuleObject; returns the HTML server handler. Without it the server cannot exist because it has no handler.
			create_server(port_number int) -> bool; creates the server with its handler. Returns true on success and throws an error for an invalid port or a duplicate call.
			set_page_content(html string) -> bool; stores the HTML served at the root path ("/").
			set_client_script(js string) -> bool; stores the JavaScript served at /rsclient.js. Call it before start_server(). If it is not set, /rsclient.js returns an empty response.
			start_server() -> bool; starts the server so it can be accessed by entering the hardware's IP address in a browser. If create_server() has not been called, it throws "RSNetwork.start_server: call create_server(port_number) first".
			process() -> bool; first sends the response buffered since the previous call, then accepts at most one new request. Returns true when it handled a request.

		request_string_data() -> string
			Returns the most recent string data received since the last process() call.
			Repeated calls return the same most recent data until a new request arrives.
			Throws "RSNetwork.request_string_data: no most recent string data" if none.

		request_int_data() -> int
			Returns the most recent int data received since the last process() call.
			Repeated calls return the same most recent data until a new request arrives.
			Throws "RSNetwork.request_int_data: no most recent int data" if none.

		request_float_data() -> float
			Returns the most recent float data received since the last process() call.
			Repeated calls return the same most recent data until a new request arrives.
			Throws "RSNetwork.request_float_data: no most recent float data" if none.

		request_boolean_data() -> bool
			Returns the most recent bool data received since the last process() call.
			Repeated calls return the same most recent data until a new request arrives.
			Throws "RSNetwork.request_boolean_data: no most recent bool data" if none.

		get_request_state() -> bool
			True only while the most recent data is unread.

		respond_string_data(value string) -> bool
			Buffers a string response for the most recent request; the next process() call sends it.
			A later response call overwrites the buffered response.

		respond_int_data(value int) -> bool
			Buffers an int response for the most recent request; the next process() call sends it.
			A later response call overwrites the buffered response.

		respond_float_data(value float) -> bool
			Buffers a float response for the most recent request; the next process() call sends it.
			A later response call overwrites the buffered response.

		respond_boolean_data(value bool) -> bool
			Buffers a bool response for the most recent request; the next process() call sends it.
			A later response call overwrites the buffered response.

		## The respond_* functions throw "RSNetwork.respond_<type>_data: no request awaiting a response" if there is no current request.

	rules:
		- Browser requests use URL query parameters, for example /call/add?value=5. Only the most recent request is kept.
		- The server keeps at most one pending request. Older requests are dropped.
		- The most recent typed data wins. Repeated calls to the same request function still return that most recent value.
		- Response text is true -> "true", 5 -> "5", 1.5 -> "1.5".
		- A later respond_*_data() call overwrites the buffered response.
		- A request becomes read on the first request_*_data() call for it. get_request_state() reports whether the current request has been read; get_request_state() itself does not mark it read.
		- After a request has been read, the buffered response is sent on the next process() call. If no response was buffered, the browser receives an empty body.
		- On PC the Wi-Fi functions throw a ModuleError. On PC the HTML server binds to 127.0.0.1; on ESP32 it binds to the device's Wi-Fi IP address.

	client script:

		The script is provided to the module with set_client_script(js string) and served at /rsclient.js.
		One script is enough for every page; it does not have to be written into each HTML page.
		The page only declares which button calls which name.

		HTML in the page:

			<input id="num" value="5">

			<button rs-call="add" rs-value-from="#num" rs-target="#out">
				Send
			</button>

			<output id="out">...</output>

			<script src="/rsclient.js"></script>

		rsclient.js:

			(() => {
				function readValue(el) {
					const from = el.getAttribute("rs-value-from");
					if (from) {
						const source = document.querySelector(from);
						return source ? source.value : "";
					}
					return el.getAttribute("rs-value") || "";
				}

				async function callElement(el) {
					const name = el.getAttribute("rs-call");
					const targetSelector = el.getAttribute("rs-target");
					const target = targetSelector ? document.querySelector(targetSelector) : null;

					if (!name) return;

					const value = readValue(el);
					const url = "/call/" + encodeURIComponent(name) +
						"?value=" + encodeURIComponent(value);

					try {
						const response = await fetch(url);
						const text = await response.text();
						if (target) target.textContent = text;
					} catch (error) {
						if (target) target.textContent = "Error: " + error.message;
					}
				}

				document.querySelectorAll("[rs-call]").forEach(el => {
					el.addEventListener("click", () => callElement(el));
				});
			})();

	Usage:
	<include> RSNetwork

	c FPS float = 10.0
	v page ModuleObject = RSNetwork.html_server_handler()
	c port_number int = 8080
	c rsclient_js string = "..." ## the rsclient.js script from the client script section, as one escaped string literal
	v html_page_content string = "<!DOCTYPE html> <html><head><title>My Page</title></head><body><input id='num' value='5'><button rs-call='add' rs-value-from='#num' rs-target='#out'>Send</button><output id='out'>...</output><script src='/rsclient.js'></script></body></html>"

	START():
		## On ESP32, connect to Wi-Fi first (see the Wi-Fi usage above).
		page.create_server(port_number)
		page.set_page_content(html_page_content)
		page.set_client_script(rsclient_js)
		page.start_server()

	PROCESS(FPS):
		page.process()
		if page.get_request_state():
			v data_from_page int = page.request_int_data()
			page.respond_string_data("ok")
