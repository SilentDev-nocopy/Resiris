HISTORICAL DESIGN NOTES - NOT THE CURRENT BACKEND DESCRIPTION
============================================================

The current CppResy CLI implements RSSignal as an in-memory desktop
simulation; it does not connect to an ESP32. Consult
`../info/rssignal_module.txt` for the implemented behavior and
`../info/esp32_gpio_table.txt` for the separate WROOM-32 hardware reference.
This file preserves the original hardware-module design idea.

Name: RSSignal@ESP32-WROOM-32 ## The "@" is required because it specifies which ESP this module works with.

The Resiris module which provides the GPIOs usage. Sending and receiving data from them.

functions:
    set_signal_mode(GPIO_constant_name, TRUE) #or FALSE
    send_signal(GPIO_constant_name) # RSSignal.send_signal(RSSignal[GENERAL_DIGITAL_GPIO4]) or v pin int = RSSignal[GENERAL_DIGITAL_GPIO4] then RSSignal.send_signal(pin)
    stop_signal(GPIO_constant_name) # RSSignal.stop_signal(RSSignal[GENERAL_DIGITAL_GPIO4]) or v pin int = RSSignal[GENERAL_DIGITAL_GPIO4] then RSSignal.stop_signal(pin)

    get_signal_mode(GPIO_constant_name) # gives back the given gpio's signal mode. TRUE or FALSE
    get_digital_data(GPIO_constant_name) # gives back the given gpio's digital data. TRUE for HIGH, FALSE for LOW.
    get_analog_data(GPIO_constant_name) # gives back the given gpio's analog data.
    # Throw an error if code tries to set GPIO34, GPIO35, GPIO36, or GPIO39 as outputs; these pins are input-only.
