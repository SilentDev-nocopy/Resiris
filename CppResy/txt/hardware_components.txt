Custom Calculator – Components

The goal is a custom, programmable scientific calculator, mainly for school and home use.

1. ESP32-WROOM-32

CPU: Dual-Core Xtensa LX6
Clock speed: max. 240 MHz
RAM: approx. 520 KB SRAM
Flash: typically 4 MB
Wi-Fi: 2.4 GHz
Bluetooth: Classic + BLE
GPIO: 34
ADC: 12-bit
Communication: UART, SPI, I²C
Power: 3.3 V for the chip
Development board: programmable via USB

This will be the brain of the calculator. It handles the buttons, the display, the calculations, and the custom programs.

2. OLED Display

Type: OLED
Size: 2.42"
Resolution: 128 × 64 pixels
Color: monochrome
Controller: SSD1309
Communication: I²C / SPI
Power: 3.3–5 V
Touch: none
Dimensions: approx. 71 × 43.5 mm

In the project it will likely communicate with the ESP32 via an I²C connection.

3. Keyboard

Switches: tactile push button
Legs: 4
Design: Through-Hole (THT)
Size: 12 × 12 mm variants
Kit: 250 pcs, various sizes/heights
Planned number of buttons: approx. 40–50 pcs
Wiring: button matrix

The buttons will provide access to basic operations and scientific functions, such as sin, cos, tan, log, ln, square root, power, parentheses, etc.

4. Communication and Data Transfer

PC ↔ calculator: The ESP32 development board connects to the computer via USB. This will be used to upload firmware, debug, and later build a custom data transfer system.

Transferring programs: We can create our own program format for the calculator. From the PC program, custom programs can be sent to the calculator via USB, which can then be stored in the ESP32's Flash memory.

Possible system:
PC → USB → ESP32 → Flash memory
PC → USB → ESP32 → loading/running a program

Later, we can create a custom PC program in which the calculator's programs can be written, edited, uploaded, and deleted.

ESP32 and display: I²C or SPI connection.

ESP32 and keyboard: via GPIOs, using matrix wiring.

5. Programming

Firmware: C/C++
Development: VS Code + PlatformIO
The firmware's task: computation engine, keyboard, OLED, memory, menu system, and program management.

Later, we can also create our own simple programming language/interpreter, so separate programs can be written for the calculator.

6. Power Supply

Not yet selected. We will first build and measure the prototype's power consumption, then choose the battery or other power supply accordingly.

7. Additional Components

Breadboard – for the first prototype
Jumper/Dupont wires – for wiring
PCB – only after the working prototype
Case – later, likely a custom/3D-printed design
